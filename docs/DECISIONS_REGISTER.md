| C-33 | Canonical content and hashes | All hashes are plain lowercase SHA-256 hex (`core.domain.hashing`) over canonical JSON (keys sorted, no whitespace, ASCII-escaped). **JSON values:** str, int, bool, null, list, object only; floats are rejected. **Resource fingerprint** = SHA-256 of the canonical JSON of the object with exactly the keys `attributes`, `logical_identity`, `references`, `resource_type`, `security_attributes`, `semantic_attributes`; each `references` entry has exactly the keys `reference_type`, `resolution_status`, `source_attribute`, `target_address` (no `source_address`), entries sorted by (source_attribute, target_address, reference_type, resolution_status) and unique; address, record_id, provenance and support_status are excluded. Golden example: `{"attributes":{"instance_type":"t3.micro","tags":{"Env":"dev","Name":"app"}},"logical_identity":{"name":"app"},"references":[{"reference_type":"security_group","resolution_status":"SUPPORTED","source_attribute":"vpc_security_group_ids","target_address":"aws_security_group.web"}],"resource_type":"aws_instance","security_attributes":{},"semantic_attributes":{"role":"app"}}`. **`resource_set_hash`** = SHA-256 of the object with exactly the keys `normalization_version` and `resources`, where `resources` is a list sorted by address of objects with exactly the keys `address`, `fingerprint`, `resource_type`: `{"normalization_version":"norm-1","resources":[{"address":"aws_instance.app","fingerprint":"<resource fingerprint>","resource_type":"aws_instance"},...]}`. A candidate's `state_hash` = its `resource_set_hash`. **Trusted `state_hash`** = SHA-256 of the object with exactly the keys `invariants`, `lineage_id`, `normalization_version`, `resources`, `version`, where `resources` has the same entry form as above and `invariants` is a list sorted by (invariant_id, invariant_version) of objects with exactly the keys `invariant_id`, `invariant_version`, `status`: `{"invariants":[{"invariant_id":"INV-FUNC-001","invariant_version":1,"status":"PROTECTED"},...],"lineage_id":"<uuid>","normalization_version":"norm-1","resources":[...],"version":0}`. These key names follow Doc 05 §30 in structure; `invariant_id` and `invariant_version` are used where §30's illustration writes `id` and `version`. Evidence ids, record ids and timestamps are never hashed (Doc 05 §27). A promoted state's `resource_set_hash` must equal its candidate's `state_hash`. **Patch `content_hash`:** SHA-256 of the UTF-8 content with CRLF and CR normalized to LF. Provisional: P3a may revise the resource payload under a new normalization_version and ADR-003. The goldens in `tests/unit/test_canonical_hashes.py` pin these payloads. | Accepted 1 Oct 2026 (P1a) |
